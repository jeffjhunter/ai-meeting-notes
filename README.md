## The outcome

Turn messy meeting notes into decisions, owners, deadlines, and follow-up that survives the meeting. This skill covers transcripts, raw notes, action items, owners, deadlines, and follow-up tracking.

## What you get

A readable recap with decisions, open questions, action items, owners, deadlines, and a follow-up list.

## Quick start

1. Install the ClawHub skill: `ai-meeting-notes`
2. Run `/ai-meeting-notes`
3. Paste the transcript or notes. Name the meeting goal and participants when known, then ask for the summary and action register.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /ai-meeting-notes with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
